# YuVault

## 插件用途
适配 Minecraft 1.8.x-1.26.x 的 Spigot、Paper、Paper 衍生端与 Mohist、Arclight、Youer 等混合端虚拟保险柜插件，支持 SQLite/MySQL、权限动态槽位、回收箱和 GUI 管理。

## 分类与标签
分类: tools
标签: 保险柜, 虚拟仓库, 跨服, MySQL, SQLite, GUI, 跨版本, 混合端, Mohist, Arclight, Youer, 工具

## 安装
```bash
首次启动后编辑 plugins/YuVault/config.yml 与 messages.yml
```
