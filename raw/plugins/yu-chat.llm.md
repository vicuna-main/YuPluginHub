# YuChat

## 插件用途
适配 Minecraft 1.8.x-1.26.x 的 Spigot、Paper、Paper 衍生端与 Mohist、Arclight、Youer 等混合端聊天称呼、昵称、前后缀、悬浮消息和显示同步插件。

## 分类与标签
分类: tools
标签: 聊天, 称呼, 昵称, 前后缀, PlaceholderAPI, LuckPerms, Vault, PlayerPoints, SQLite, MySQL, 跨版本, 混合端, Mohist, Arclight, Youer, 工具

## 安装
```bash
首次启动后编辑 plugins/YuChat/config.yml、messages.yml、gui.yml、titles.yml 与 effects.yml
```
