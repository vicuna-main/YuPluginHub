⚙️ Yu Auth 配置说明 ​

最小配置 ​

yaml
enabled: true
locale: zh_CN
storage:
  type: file
log:
  level: info

生产配置建议 ​

yaml
enabled: true
locale: zh_CN
storage:
  type: mysql
  tablePrefix: yu_auth_
cache:
  ttl: 300
security:
  audit: true

配置拆分建议 ​

  • 公共配置放在主配置文件。
  • 密钥、数据库密码等敏感内容通过环境变量或私有配置注入。
  • 不要把生产配置发布到公开页面或共享给无关人员。

可视化说明 ​

该插件详情首页支持通过 hero.background 配置独立背景图，也支持 banner 配置卡片主视觉。
