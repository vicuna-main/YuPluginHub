文档入口 ​

YuVault 是面向 Minecraft 1.8.x-1.26.x 的跨版本虚拟保险柜插件，环境适配范围与 YuTeleport 保持一致：Spigot、Paper、Paper 衍生端，以及 Mohist、Arclight、Youer 等 Bukkit API 混合端。它把玩家保险柜、跨服 MySQL 存储、权限动态容量、物品黑白名单和回收箱流程整合到一个轻量 GUI 插件里，适合生存服、模组服、RPG 服和多子服共享背包扩展场景。

安装部署构建、放置 jar、首次启动、运行时依赖、SQLite/MySQL 与上线检查命令手册/yvault、/yv、/vault 的打开、列表、创建、删除、回收与管理命令配置说明数据库、槽位模式、世界与物品控制、列表 GUI、回收箱和依赖校验权限节点玩家基础权限、管理员权限、动态保险柜数量和动态槽位容量插件联动MySQL 跨服、权限插件、菜单插件、世界限制、bStats 与文件结构常见问题打不开保险柜、权限容量不生效、MySQL 连接、依赖下载和防吞物品排查

核心能力 ​

能力说明
广版本与混合端适配面向 1.8.x-1.26.x，覆盖 Spigot、Paper、Paper 衍生端，并兼顾 Mohist、Arclight、Youer 等混合端运行环境。
虚拟保险柜玩家可通过命令或 GUI 打开自己的保险柜，管理员可查看、创建、调整和删除他人保险柜。
SQLite/MySQL 存储单服默认使用 SQLite；跨服共享可切换 MySQL，并通过 HikariCP 管理连接池。
权限动态容量支持 yuvault.vaults.<数量> 控制保险柜数量，支持 yuvault.slots.<编号>.<行数> 控制指定保险柜行数。
命令槽位模式可将 slot-mode 切到 command，用 /yvault setslots 固定写入保险柜行数。
GUI 列表/yvault gui 展示保险柜列表，支持空状态创建入口、翻页、关闭和返回主菜单命令。
物品回收箱缩小槽位或删除保险柜时，超出物品会进入回收箱，玩家可用 /yvault reclaimed 取回。
世界与物品控制支持世界黑白名单、物品黑白名单和通配符匹配，避免特定世界或高风险物品进入保险柜。
防吞物品保护保存、缩容、删除和反序列化失败时会拒绝覆盖风险数据，并提示管理员查看控制台。
运行时依赖加载首次启动会缓存 HikariCP、SQLite JDBC、MySQL JDBC、SLF4J 等依赖到插件目录并校验哈希。
统计接入内置 bStats Bukkit 统计，插件 ID 为 31043。

快速开始 ​

  1. 构建或获取发布版 YuVault-1.1.0.0-all.jar。
  2. 将 jar 放入服务端 plugins/ 目录并启动一次服务器。
  3. 打开 plugins/YuVault/config.yml，确认 storage.type、default-vaults、slot-mode 和世界/物品限制。
  4. 给普通玩家分配 yuvault.use、yuvault.reclaimed，再按需求分配 yuvault.vaults.<数量> 与 yuvault.slots.<编号>.<行数>。
  5. 玩家使用 /vault、/yv 或 /yvault 打开保险柜；使用 /yvault gui 查看保险柜列表。
  6. 修改配置后执行 /yvault reload 重载配置与消息。

适合的服务器 ​

场景推荐用法
生存服给玩家提供额外仓储，使用权限控制默认数量和每个保险柜容量。
模组服配合物品黑名单屏蔽高风险方块、命令方块或特殊 NBT 物品。
多子服网络使用 MySQL 存储，让大厅、生存、资源世界共享同一套保险柜数据。
RPG 服用菜单插件打开 /yvault gui，把保险柜当作角色仓库或会员容量权益。
强安全服保持回收箱和防吞物品保护流程，缩容、删除前先备份数据库。
