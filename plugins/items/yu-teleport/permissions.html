YuTeleport 权限节点 ​

权限总览 ​

权限默认说明
yuteleport.adminop管理权限集合，包含随机传送、重载、warp、home、tpa、back、分享和绕过权限。
yuteleport.usetrue允许使用 /yuteleport、/ytp、/rtp 随机传送。目标玩家自助或被代传送时都需要该权限。
yuteleport.biomeop允许使用 biome:<模式> 指定单次随机传送的目标生物群系。
yuteleport.teleport.othersop允许用 /yuteleport <玩家> [世界] 随机传送其他玩家。
yuteleport.reloadop允许执行 /yuteleport reload。
yuteleport.sharetrue允许分享传送成功后的当前位置。
yuteleport.bypass.cooldownop跳过随机传送、warp、home、tpa、back 和分享冷却。
yuteleport.bypass.cooldown.othersop管理员代传送其他玩家时无视目标玩家冷却。
yuteleport.bypass.costop跳过随机传送、warp、home、tpa、back 和分享费用。
yuteleport.bypass.waitop跳过随机传送、warp、home、tpa、back 等待时间。

Warp 权限 ​

权限默认说明
yuteleport.warp.usetrue允许使用 /warp 查看和传送可见 warp。
yuteleport.warp.settrue允许使用 /setwarp 创建或更新 warp。
yuteleport.warp.deletetrue允许删除自己的 warp。
yuteleport.warp.publictrue允许公开或取消公开自己的 warp。
yuteleport.warp.adminop允许编辑、删除所有玩家的 warp。
yuteleport.warp.limit.bypassop允许无视 warp 数量过期锁定。
yuteleport.warps.*op允许使用所有 restricted warp。
yuteleport.warps.<名称>false允许使用指定 restricted warp。
yuteleport.warp.limit.<数量>false动态提高可创建 warp 数量，例如 yuteleport.warp.limit.25。
yuteleport.warp.limit.unlimitedfalse不限制可创建 warp 数量。

Home 权限 ​

权限默认说明
yuteleport.home.usetrue允许使用 home 传送和查看自己的 home。
yuteleport.home.settrue允许设置或更新 home。
yuteleport.home.deletetrue允许删除 home。
yuteleport.home.othersop允许查看或使用在线玩家的 home，也可用管理语法删除在线玩家 home。
yuteleport.home.publictrue允许公开或取消公开自己的 home。
yuteleport.home.limit.bypassop允许无视 home 数量过期锁定。
yuteleport.home.limit.<数量>false动态提高可拥有 home 数量，例如 yuteleport.home.limit.25。
yuteleport.home.limit.unlimitedfalse不限制可拥有 home 数量。

TPA 权限 ​

权限默认说明
yuteleport.tpa.usetrue允许使用 /tpa、/tpaccept、/tpdeny、/tpacancel。
yuteleport.tpa.heretrue允许使用 /tpahere。
yuteleport.tpa.ignoretrue允许忽略发给自己的 TPA 请求。
yuteleport.tpa.allop允许向全服玩家发送 tpahere 请求。

Back 权限 ​

权限默认说明
yuteleport.back.*op/back 权限集合，包含使用、死亡点、清空和管理权限。
yuteleport.back.usetrue允许使用 /back、/back list 和点击历史条目返回。
yuteleport.back.deathtrue允许使用 /back death，并允许在历史列表和无参数 /back 中访问死亡记录。
yuteleport.back.cleartrue允许执行 /back clear 清空自己的 back 历史。
yuteleport.back.adminop管理类 /back 权限节点，供权限组归类和后续管理能力使用。

权限组 ​

text
yuteleport.group.<组名>

该权限用于匹配 config.yml 中的 groups.<组名>。玩家同时命中多个组时，使用配置中靠前的组。

普通玩家组 ​

text
yuteleport.use
yuteleport.warp.use
yuteleport.warp.set
yuteleport.warp.delete
yuteleport.home.use
yuteleport.home.set
yuteleport.home.delete
yuteleport.tpa.use
yuteleport.tpa.here
yuteleport.tpa.ignore
yuteleport.back.use
yuteleport.back.death
yuteleport.back.clear
yuteleport.share

适合普通生存服玩家。世界可用性应优先通过 teleports.defaults.world-access 控制，而不是只依赖权限。

VIP 或赞助组 ​

text
yuteleport.group.vip
yuteleport.bypass.cooldown

如果希望 VIP 不受等待限制，额外给予：

text
yuteleport.bypass.wait

如果希望 VIP 免扣费，额外给予：

text
yuteleport.bypass.cost

如果希望 VIP 获得更多数量上限，可使用：

text
yuteleport.warp.limit.25
yuteleport.home.limit.25

管理员组 ​

text
yuteleport.admin

yuteleport.admin 已包含常用管理权限。若不想给完整管理权限，可拆分给予 yuteleport.reload、yuteleport.teleport.others、yuteleport.warp.admin、yuteleport.home.others、yuteleport.tpa.all、yuteleport.back.admin。

控制台与命令方块 ​

控制台没有玩家位置，不能执行无参数 /yuteleport、/ytp 或 /rtp。控制台可使用：

text
yuteleport <玩家>
yuteleport <玩家> <世界>
yuteleport reload

控制台权限由服务端命令系统处理，通常不需要额外配置权限插件。
