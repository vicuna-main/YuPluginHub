文档入口 ​

YuChat 是面向 Minecraft 1.8.x-1.26.x 的跨版本聊天称呼与昵称插件，环境适配范围与 YuTeleport 保持一致：Spigot、Paper、Paper 衍生端，以及 Mohist、Arclight、Youer 等 Bukkit API 混合端。它把玩家称呼、昵称、个性签名、自定义死亡消息、LuckPerms 前后缀、PlaceholderAPI 变量、经济购买、GUI 管理和 TAB/头顶名同步整合到一个聊天显示插件里，适合生存服、RPG 服、会员体系服务器和需要细致身份展示的社区服。

核心能力 ​

能力说明
广版本与混合端适配面向 1.8.x-1.26.x，覆盖 Spigot、Paper、Paper 衍生端，并兼顾 Mohist、Arclight、Youer 等混合端运行环境。
称呼系统支持内置称呼和 custom_titles.yml 自定义称呼，玩家可同时激活多个称呼并按激活顺序显示。
昵称与格式支持昵称唯一校验、黑名单、正则、长度、冷却、昵称颜色、昵称格式和普通玩家颜色权限限制。
LuckPerms 显示可通过 LuckPerms API 读取 prefix、suffix、meta，也可在接口不可用时按配置用 PlaceholderAPI 兜底。
聊天与悬浮支持聊天格式、聊天内容颜色、MiniMessage/Hex 降级、前缀/后缀/昵称/称呼悬浮文本。
显示同步可同步 Bukkit displayName、TAB 列表、scoreboard-team 头顶名，必要时可切换 hologram 头顶名模式。
个性签名和死亡消息玩家可设置个性签名和自定义死亡消息，死亡原因、击杀者和悬浮内容均可配置。
经济购买支持 Vault 金币、PlayerPoints 点券、两者都扣或二选一，用于昵称、签名、死亡消息、颜色和称呼。
SQLite/MySQL 存储单服默认 SQLite；跨服或多子服共享可切换 MySQL，并统一使用表名前缀。
GUI 管理玩家可用 GUI 切换称呼、颜色和显示开关；管理员可在 GUI 中创建称呼、调整经济和 LuckPerms 显示。
运行时依赖加载首次启动会缓存 HikariCP、SQLite JDBC、MySQL JDBC、SLF4J 等依赖到插件目录并校验哈希。
统计接入内置 bStats Bukkit 统计，插件 ID 为 31412。

快速开始 ​

  1. 在 Yu 插件交流群获取免费版 1.0.6，或通过爱发电赞助获取高级版。
  2. 将 jar 放入服务端 plugins/ 目录并启动一次服务器。
  3. 打开 plugins/YuChat/config.yml，确认 storage.type、chat-format.format、prefix-suffix 和 display 配置。
  4. 给普通玩家分配 yuchat.use、yuchat.gui、yuchat.nickname.use，按需要分配称呼、颜色和格式权限。
  5. 玩家使用 /yc、/chat 或 /yuchat 打开主界面，使用 /yc nick <昵称> 快速修改昵称。
  6. 修改配置后执行 /yc reload 重载配置、消息和 GUI。

适合的服务器 ​

场景推荐用法
生存服作为统一聊天格式与昵称插件，配合 LuckPerms 展示权限组前后缀。
RPG 服使用称呼、称呼颜色和个性签名表达职业、阵营、声望或活动身份。
会员服将称呼、昵称颜色、聊天颜色和死亡消息接入 Vault 或 PlayerPoints。
多子服网络使用 MySQL 存储，让大厅、生存、资源服共享玩家聊天显示数据。
社区服通过 GUI 降低玩家自助配置门槛，同时保留管理员后台配置能力。
