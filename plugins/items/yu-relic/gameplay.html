YuRelic 玩家玩法 ​

一分钟上手 ​

  1. 主手拿一件可损耗装备，例如剑、斧、弓、盾、护甲或工具。
  2. 输入 /yurelic open 打开开光 GUI，或 /yurelic open basic|refined|exalted 选择档位。
  3. 开光后使用这件装备战斗、挖掘、承伤或完成服务器配置的目标来获得灵器经验。
  4. 用 /yurelic info 或 /yurelic gui 查看等级、经验、器魂、灵契、路线、器体状态。
  5. 到达突破点后输入 /yurelic breakthrough 查看候选路线，再用 /yurelic breakthrough 1 等命令选择。
  6. 器体损耗过高时用 /yurelic repair 或 /yurelic repair resource <灵材> 修复。

核心循环 ​

text
开光物品
  -> 建立灵契与器体
  -> 通过真实使用获得灵息经验
  -> 等级提升并积累命痕
  -> 突破选择成长路线
  -> 注魂、铭魂、淬炼、觉醒
  -> 器藏收录、天榜展示、传承或封存

YuRelic 默认不把装备改成普通数值面板，而是把成长信息写入灵器数据与 Lore。服务器可以通过 GUI 和 PlaceholderAPI 把这些信息显示到菜单、面板、排行榜或聊天分享里。

开光与器体 ​

开光会读取主手物品类型、名称、Lore、现代 key、NBT 指纹和耐久信息。默认要求物品能读取最大耐久；无耐久模组物品需要服主加入 rpg.non-durable-relics.whitelist。

开光档位常见含义：

档位用途
basic基础开光，适合玩家日常装备
refined精炼开光，成本更高，品质权重更好
exalted高阶开光，通常接 Vault、PlayerPoints 或灵材消耗

器体是灵器自己的寿命概念。原版铁砧修复不等于恢复器体；半损毁后需要 YuRelic 修复体系处理。

灵契、同调与器忆 ​

开光者默认成为初代器主。只有当前器主长期使用灵器时，灵器才稳定回应并成长。其他玩家持有时可能进入成长沉默。

常用命令：

  • /yurelic pact info：查看器主、初照、契序与涤契成本。
  • /yurelic pact rebind：涤契归心，让灵器重新认主。
  • /yurelic affinity info：查看同调等级。
  • /yurelic affinity meditate [注入量]：通过配置的成本通道提高同调。
  • /yurelic affinity memory：查看器忆文本。

成长、突破与道韵 ​

灵器经验来自战斗、击杀、采掘、承伤、远程、格挡、经验吸收等行为，具体倍率由服主配置。插件会考虑耐久门禁、反刷、灵息疲劳、LevelledMobs 等级、场景规则和世界倍率。

到达突破等级后，灵器会生成候选路线。路线会影响后续攻击、防御、成长、修复、控制或辅助倾向。长期按某条路线使用灵器，还会沉淀道韵精通：

  • /yurelic breakthrough：查看或选择突破路线。
  • /yurelic mastery：查看道韵精通。
  • /yurelic combat：查看当前战斗乘区与 PVP/PVE 压缩。

器魂、潜质、天赋与觉醒 ​

灵器拥有器魂、潜质、六维命痕、天赋和觉醒状态。服主可以通过成本配置控制这些系统的节奏。

系统命令作用
器魂`/yurelic soul infofeed
潜质`/yurelic potential infoupgrade`
天赋`/yurelic talent listprepare
觉醒`/yurelic awaken infostart`
器魂共鸣自动触发高魂级后获得专属战斗或成长效果

资源、仪式与灵材 ​

灵材来自掉落、里程碑、活动、商城或管理员发放。常见灵材包括潜质精华、换魂玉、洗练石、觉醒核心、玄刻尘、修灵晶等。

  • /yurelic resource：查看背包中的 YuRelic 资源。
  • /yurelic repair resource <灵材> [数量|all]：投入灵材修复。
  • /yurelic shop：打开灵物坊，使用配置货币购买灵材。
  • /yurelic loot：查看掉落生态状态。

饰品、套装与构筑 ​

YuRelic 支持虚拟饰品槽，默认有灵佩、魂坠、戒印、符令四类槽位。饰品槽可以通过权限、等级或材料解锁。

  • /yurelic accessory list：查看槽位。
  • /yurelic accessory equip [槽位]：将主手饰品灵器佩戴到虚拟槽。
  • /yurelic accessory unequip [槽位]：卸下。
  • /yurelic accessory unlock [槽位]：按配置消耗解锁。
  • /yurelic sets：查看套装共鸣。

目标命令

GUI 入口 ​

输入 /yurelic 或 /yurelic gui 通常会打开主菜单。常见页面包括开光、养成、修复、饰品、器藏、天榜、灵物坊、运维、掉落模拟等。GUI 按钮仍调用底层命令，因此权限和配置逻辑保持一致。
