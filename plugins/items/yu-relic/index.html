文档入口 ​

YuRelic 是面向 Minecraft 服务器的灵器成长 RPG 插件。它把武器、防具、工具、饰品等物品转化为可成长、可突破、可传承、可跨服追踪的灵器，并提供内建 GUI、掉落生态、诊断工具、PlaceholderAPI 与 Bukkit 事件接口。

安装部署环境要求、发布包获取、动态依赖、首次启动和升级检查玩家玩法从开光到成长、突破、器魂、饰品、器藏与灵护的完整路线命令手册玩家、管理员、运维与插件联动命令按用途归类配置说明模块化配置、存储、联动、经济、GUI、掉落和防复制权限节点玩法、系统、管理、高危操作和倍率权限PlaceholderAPI灵器状态、开光判断、菜单面板和天榜变量Bukkit 事件开光、成长、战斗、资源、市场和天榜监听插件联动软依赖、EasyBot 广播和集成建议常见问题不能开光、不长经验、依赖失败、数据库异常、重复 ID 等排障

当前版本定位 ​

  • 当前说明覆盖：赞助版 1.0.13.31 的完整能力，并保留免费版 1.0.0 的入门信息。
  • 主命令：/yurelic，别名包含 /yr、/yrelic、/relic，并保留 /yurpg、/yrpg 作为迁移兼容。
  • 配置入口：plugins/YuRelic/config.yml，实际默认配置拆分到 configs/01-core.yml 至 configs/09-loot-integrity-scene.yml。
  • 数据原则：物品 NBT 是主真相源；SQLite/MySQL 用于跨服索引、审计、防复制、天榜和恢复辅助。
  • 兼容策略：目标运行环境为 Minecraft 1.8.x - 1.26.x、JDK 8 及以上；当前已测试环境为 1.21.1。

插件预览 ​

下面截图覆盖灵器 Lore、开光/养成 GUI、修复、掉落、天榜、器藏、诊断和玩法面板等常用场景，方便服主快速判断它是否适合自己的服务器节奏。

适合谁 ​

  • 生存服：想让原版或模组装备拥有长期养成、修复、保值和展示价值。
  • RPG 服：需要成长路线、器魂、天赋、觉醒、掉落、战斗乘区和副本区域倍率。
  • 群组服：需要跨服 MySQL、灵器软锁、审计、重复 ID 巡检和 STORAGE 天榜。
  • 运维团队：需要 Doctor GUI、掉落模拟 GUI、动态依赖状态、配置版本检查和导出报告。
  • 附属插件作者：需要事件、占位符、权限和低耦合集成点。
