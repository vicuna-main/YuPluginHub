YuRandomTeleport Java API ​

1.2.0.0 通过 Bukkit ServicesManager 注册 YuRandomTeleportApi。接入方应把 YuRandomTeleport 写入 depend 或 softdepend，不要强转插件主类，也不要访问内部集合。

获取 API ​

java
RegisteredServiceProvider<YuRandomTeleportApi> registration =
    Bukkit.getServicesManager().getRegistration(YuRandomTeleportApi.class);
YuRandomTeleportApi api = registration == null ? null : registration.getProvider();

消费插件的 plugin.yml：

yaml
softdepend: [YuRandomTeleport]

请求传送 ​

java
api.requestTeleport(player, world).thenAccept(result -> {
    if (result.isSuccess()) {
        Location destination = result.getDestination();
    }
});

requestTeleport(Player, World) 返回 CompletableFuture<TeleportResult>，并沿用命令相同的权限、世界黑白名单、冷却、等待、经济与安全规则。不要阻塞等待 future；在 Folia 上也不要假定回调属于某个固定区域，需要操作实体或世界时应重新使用服务端调度器。

API 方法 ​

方法说明
requestTeleport(Player, World)按完整策略异步请求一次随机传送。
cancelTeleport(Player, TeleportCancelReason)取消玩家正在进行的请求；返回是否确实取消。
isPending(UUID)玩家是否处于等待或搜索状态。
getCooldownRemainingMillis(UUID)剩余冷却毫秒数。
getSnapshot(UUID)获取不可变的最近状态/位置快照。
getSuccessfulTeleports()本次启动以来成功次数。
getFailedTeleports()本次启动以来失败次数。
getCancelledTeleports()本次启动以来取消次数。
isFolia()当前是否运行在 Folia 调度模型。

返回值与状态 ​

TeleportResult 提供玩家 UUID、TeleportStatus、世界名、克隆后的目标 Location、时间戳与 isSuccess()。可能的状态：

text
IDLE, PENDING, SEARCHING, SUCCESS, NO_SAFE_LOCATION,
CANCELLED, REJECTED, TELEPORT_FAILED, PLAYER_OFFLINE, ERROR

TeleportSnapshot 提供状态、世界、X/Y/Z 与更新时间。getSnapshot 返回 Optional；尚无状态时不要直接调用 get()。

主动取消可使用：

java
api.cancelTeleport(player, TeleportCancelReason.API);

取消原因包括 MOVEMENT、DAMAGE、INTERACTION、CHAT、COMMAND、DISCONNECT、API、EVENT、PLUGIN_DISABLE。

事件与 PlaceholderAPI ​

  • 生命周期事件与线程注意事项见 Bukkit 事件。

其他联动 ​

联动行为
Vault可选软依赖；启用经济后通过服务注册查找 Economy，成功传送后扣费。
PlaceholderAPI可选软依赖；只读快照，不加载区块、不查询 Vault。
bStatsBukkit 统计插件 ID 30589；关闭不会影响传送。
控制台命令回调commands.on-teleport/on-success/on-fail 由控制台执行，可接任务、广播和日志插件。

控制台回调不要带 /。通用变量为 {player}、{sender}、{world}；成功阶段增加 {x}、{z}，失败阶段增加 {reason}。

文件与网络行为 ​

  • 读写 plugins/YuRandomTeleport/config.yml。
  • 提取并读取 plugins/YuRandomTeleport/lang/*.yml，单文件上限 2 MiB。
  • 兼容读取旧 plugins/YuRandomTeleport/messages.yml。
  • 配置升级时创建 .bak 或损坏文件备份。
  • bStats 启用时会访问其统计服务；核心传送本身不依赖外网。
