文档入口 ​

YuRandomTeleport 1.2.0.0 是面向 Minecraft 1.8.x-1.26.x 的跨版本安全随机传送插件。新版在原有的世界规则、经济与安全落点能力上，加入 Folia 调度、Paper 异步传送、公开 Java API、可取消生命周期事件、PlaceholderAPI 和多语言系统。

安装部署构建、放置 jar、首次启动、Vault 经济接入和升级检查命令手册/yurtp 与 /rtp 的玩家用法、管理员代传送和重载命令配置说明世界黑白名单、半径、高度、安全方块、等待打断和自定义控制台命令权限节点普通玩家、管理员、绕过冷却、绕过费用和跳过等待PlaceholderAPI冷却、状态、平台、统计和最近传送位置变量Bukkit 事件开始、目标点、取消与完成四个传送生命周期事件Java API异步请求、主动取消、快照、计数器与平台检测常见问题找不到安全点、无法扣费、等待被取消、下界配置和世界限制排查

核心能力 ​

能力说明
广版本与混合端适配面向 1.8.x-1.26.x，覆盖 Spigot、Paper、Paper 衍生端，并兼顾 Mohist、Arclight、Youer 等混合端运行环境。
安全随机传送在配置半径内随机抽取 X/Z，加载区块后检查脚下方块、脚部空间、头部空间和头顶额外空气。
主世界与下界适配普通世界使用最高地表作为候选点；下界会在高度范围内随机扫描 Y 轴，避免只抽少量高度导致卡墙。
世界访问控制支持 world-blacklist 黑名单和 world-whitelist 白名单；白名单非空时优先生效。
按世界覆盖每个世界可单独设置费用、半径、高度、安全检查、禁止方块和允许方块。
等待与打断可配置传送前等待秒数；移动、受伤、交互、聊天、执行命令或离线可取消等待中的传送。
冷却与扣费内置冷却；开启经济后通过 Vault 调用服务端经济插件扣费。
自定义反馈可在传送开始、成功、失败时由控制台执行命令，适合接入 title、音效、广播、任务或日志系统。
Folia / Paper 调度Folia 下按 Global、Region、Entity Scheduler 分派；Paper/Purpur 支持可用时调用 teleportAsync。
插件开发接口通过 Bukkit ServicesManager 暴露异步 Java API，并提供 4 个生命周期事件。
PlaceholderAPI可选注册 %yurtp_*%，只读取无锁快照，不触发区块加载或 Vault 查询。
多语言内置简体中文与英语，可按玩家客户端语言选择，并支持 lang/ 自定义语言文件。
自动配置升级插件按 config-version 合并默认配置并保留已有值；旧 messages.yml 可继续覆盖中文文本。
统计接入内置 bStats Bukkit 统计，插件 ID 为 30589。

快速开始 ​

  1. 构建或获取发布版 YuRandomTeleport-1.2.0.0-all.jar。
  2. 将 jar 放入服务端 plugins/ 目录并启动一次服务器。
  3. 打开 plugins/YuRandomTeleport/config.yml，确认 world-blacklist、半径和安全规则。
  4. 普通玩家使用 /rtp 或 /yurtp 在当前世界随机传送。
  5. 管理员可用 /yurtp <玩家> [世界] 将指定玩家随机传送到指定世界。
  6. 修改配置或语言文件后执行 /yurtp reload 热重载。

活动服使用 commands.on-success 发放标题、记录日志或触发活动系统。
高版本大地图保持安全检查开启，并按世界设置高度范围和禁止方块。
