Capabilities

围绕维护效率设计，而不是堆功能入口。

第一版保持克制：文档可读、数据可信、复制方便、统计可缓存。

文档即产品界面

插件说明、配置片段、兼容信息和复制操作保持在同一个阅读流里，减少服主来回查找。

结构化数据驱动

插件、服务器、推广位和统计映射全部由 JSON 与 Schema 管理，页面只负责稳定呈现。

统计与展示分离

bStats 数据走构建期或定时同步，前端展示缓存结果，避免页面依赖实时远程接口。

AI 友好的复制格式

每个插件文档页提供 Markdown 与 LLM 摘要复制按钮，方便把上下文带入 AI 工具。

Plugin Index

插件列表保持轻量，但每个入口都有真实上下文。

推荐插件直接连接到详情页，详情页再提供安装命令、兼容性、统计摘要和服务器案例。
