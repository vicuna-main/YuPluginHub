安全策略 ​

数据校验 ​

插件、广告、服务器和 bStats 映射都使用 Zod schema 校验。服务器展示的插件 slug 必须存在。

广告与外链 ​

广告必须标注推广或赞助。所有推广链接使用 sponsored nofollow noopener noreferrer，并要求 HTTPS。

复制格式安全 ​

站内提供的复制摘要不包含密钥、Token、内部链接或危险命令。配置示例中的敏感字段使用占位符。
